# Style Library — 10 套完整风格档案

> 每个风格定义：设计哲学、色彩、字体、空间、签名元素、适用场景、反模式。

---

## 1. Swiss International（瑞士国际主义）

**设计哲学**: 网格系统 + 理性秩序 + 编号层级。每个元素都有其存在理由。

### Visual DNA
- **色彩**: 白/黑基底 + 一个大胆强调色（红 #e63946 / 蓝 #2563eb / 琥珀 #d97706）。无渐变。
- **字体**: 仅无衬线。Noto Sans SC (中文), Helvetica Neue (英文)。标题 700-900, 正文 400。无斜体。
- **空间**: 数学精度。8mm/16mm/32mm 间距体系。信息密集。
- **形状**: 仅直角。矩形、方形、直线。无圆角、无有机形状。

### 签名元素
- **章节编号**: 大号 28-36pt 数字，强调色，在章节标题旁
- **分段线**: 细水平线 (1-2px)，黑色或强调色
- **表格**: 黑色表头白字 + 交替浅灰行 + 无竖线
- **封面**: 左侧强调色条 (8mm) + 几何色块 + 网格背景图案 3% 透明度 + 大号章节号

### 适用场景
技术文档、系统分析、数据报告、需要权威感和清晰度的任何内容。

### 反模式
- 柔和色彩、圆角、装饰性花边
- 多于一个强调色
- 间距不一致（违反网格纪律）

## 2. Japanese Editorial（日式文艺杂志）

**设计哲学**: 間 (Ma)——留白即内容。慢读节奏。每个元素都有呼吸空间。

### Visual DNA
- **色彩**: 暖纸色调 (#faf8f4 页面, #f5f0e6 底色, #3d3229 正文)。大地颜料: 赭石 #8b5a2b, 石色 #b8a890。无纯白。
- **字体**: 仅衬线。Noto Serif SC。行高 1.6-1.8（宽裕）。标题字间距略微扩展。
- **空间**: 页边距 3cm 起步。段间距大。信息稀疏——永不拥挤。
- **形状**: 有机 + 几何混合。细线、小圆点、印章矩形。

### 签名元素
- **段落标记**: 装饰符号 (Unicode: ❧ ❦ ❁) 或细线代替项目符号
- **标题**: 顶部赭石边框 (2-3px) + 底部暖灰边框。无左边框。
- **表格**: 极简三线式。无填充色、无竖线。石色顶/底边框。
- **封面**: 非对称布局（内容偏左）。竖排装饰文字 (writing-mode)。印章元素。细水平线。小圆点装饰。
- **引用块**: 浅暖色背景 (#f5f0e6) + 大型淡化引号水印

### 适用场景
个人随笔、文化内容、文学集、任何需要沉思感和温度的内容。

### 反模式
- 紧页边距、密集排版
- 粗体无衬线字体
- 高对比度配色

## 3. Cyberpunk Archive（赛博朋克档案）

**设计哲学**: 终端界面美学。数据即信仰。一切皆编码。

### Visual DNA
- **色彩**: 深色基底 (#0a0e17 页面, #0d1117 表面)。双强调色: 荧光绿 (#00ff9d) 成功/验证, 电光蓝 (#00a8ff) 信息/链接。柔和文本 (#c8d4e0 正文, #8a9aaa 次要)。
- **字体**: 正文无衬线，标签/状态等宽。Noto Sans SC + Courier New。字间距略微扩展 (0.03-0.1em)。
- **空间**: 紧凑。终端密度。信息打包但可扫描。
- **形状**: 仅锐角。细边框 (1px)，强调色 20-30% 透明度。角括号装饰。

### 签名元素
- **状态标签**: `[VERIFIED]` `[WARNING]` `[REJECT]`，彩色边框 + 等宽字体
- **段落编号**: `SEC_01 ::` `SUB_A ::` 前缀格式
- **标题**: `>>>` 前缀蓝色 + 标题绿色。底部细强调色边框。
- **表格**: 表头无填充。强调色顶/底边框。单元格边框 10% 强调色透明度。
- **封面**: 顶部绿色状态栏 + 黑色文字。角括号装饰 + 竖排二进制 + 扫描线。

### 适用场景
游戏内容、技术规格、科幻相关、系统文档、任何有"机密档案"感的内容。

### 反模式
- 暖色、有机形状
- 衬线字体
- 大页边距和呼吸空间

## 4. Warm Academic（暖调学术风）

**设计哲学**: 学术传统 + 人文温度。金褐是权威减去冰冷的距离感。

### Visual DNA
- **色彩**: 金褐 #b8a88a 为主强调色。象牙白底色 #faf8f5。深棕正文 #2c2c2c。
- **字体**: 楷体标题 (Kaiti SC) + 宋体正文 (Songti SC)。行高 1.75。
- **空间**: A4, 页边距 2-2.5cm。中等密度。
- **形状**: 细线、渐变分隔线、几何装饰（旋转矩形）。

### 签名元素
- **H1**: 楷体 20pt + 底部金褐 2px 线
- **H2**: 楷体 14pt + 左侧金褐 3px 线
- **表格**: 书眉线风格——表头上下粗线，表尾粗线
- **封面**: 渐变底色 + 大圆光晕 + 旋转矩形 + 金褐装饰线 + 楷体标题
- **引用块**: 暖灰渐变底色 + 金褐左边线
- **代码**: 浅灰底色 + 咖啡色关键字

### 适用场景
白皮书、正式报告、学术论文、任何需要"权威但不冰冷"感的内容。

### 反模式
- 纯黑纯白高对比度
- 无衬线字体
- emoji（正式文档应 `--strip-emoji`）

## 5. Classic Scholar（古典学者）

**设计哲学**: 学术传统。让内容自己说话。装饰是最小的、结构性的。

### Visual DNA
- **色彩**: 黑字 (#333)、灰线 (#999)、浅灰代码块 (#f5f5f5)。白封面。无强调色。
- **字体**: 衬线优先。Georgia 或 Noto Serif SC。11pt 正文, 1.5 行高。
- **空间**: 标准页边距 (2.5cm)。平衡密度。
- **形状**: 仅线。左侧边框用于引用。无形状、无渐变。

### 签名元素
- **定理框**: 左边界 (3px solid #333)
- **表格**: Booktabs 风格——表头粗上/下边框，无竖线
- **封面**: 白色背景，居中文本，无装饰

### 适用场景
学术论文、学位论文、正式报告。

### 反模式
- 除黑/灰/白外的任何颜色
- 装饰元素
- 非标准布局

## 6. Bauhaus Poster（包豪斯海报）

**设计哲学**: 散落几何。原色。不对称平衡。每一页都是一张构图。

### Visual DNA
- **色彩**: 原色三色——红、黄、蓝全饱和。黑字。白底。
- **字体**: 无衬线，粗体。标题层级间强烈大小对比。
- **空间**: 不对称。大面积空白与密集内容区形成对比。
- **形状**: 圆、三角、矩形散落作为装饰。允许重叠。

### 签名元素
- **重叠形状**: 彩色圆/矩形部分位于文本区后方
- **不对称布局**: 内容左对齐 + 大右页边距，或反之
- **粗体编号**: 超大行号，原色
- **封面**: 散落几何形状 + 原色 + 不对称标题

### 适用场景
创意作品集、艺术/设计文档、儿童教育材料。

### 反模式
- 对称布局
- 柔和颜色
- 传统居中对齐

---

## 7. Art Nouveau（新艺术）

**设计哲学**: 有机曲线 × 装饰性边框。手工美学的极致。

### Visual DNA
- **色彩**: 金褐 + 柔粉 + 奶白。暖调，饱和但不刺眼。
- **字体**: 装饰性衬线。中文：楷体/仿宋，英文：serif。
- **空间**: 装饰性边框定义了空间，内容在边框内。
- **形状**: S 曲线、对称圆环、花蔓边框、复杂几何图案。

---

## 8. Eastern Ink Wash（东方水墨）

**设计哲学**: 墨分五色。留白是画的延续。印章 = 落款。

### Visual DNA
- **色彩**: 宣纸底色 + 浓淡墨色。印章红点缀。
- **字体**: 宋体正文 + 行书标题（字体降级到楷体）。
- **空间**: 大量留白。竖排可选。
- **形状**: 墨点、笔触纹理、印章、竖排页眉。

---

## 9. Minimalism（极简主义）

**设计哲学**: 留白即尊重。装饰为零。让内容自己呼吸。

### Visual DNA
- **色彩**: 无强调色。黑 #333、灰 #555/#999/#ccc/#ddd、白。无饱和色。
- **字体**: 无衬线 light 字重。PingFang SC Light。标题 weight 500（不是 bold）。
- **空间**: 极大页边距（4cm）。行距 1.8。信息密度低。
- **形状**: 仅水平细线 0.5px。无几何装饰、无圆角、无色块。

### 签名元素
- **封面**: 居中文字 + 上下细竖线 1px + 30px 黑色分隔线 + 16pt light 标题
- **标题**: H1 极细 0.5px 灰底线 / H2-3 极轻，无装饰
- **表格**: 极简三线式 0.5px 灰线，无填充色
- **TOC**: 无编号，无 leader（仅 0.5px 灰分隔线）

### 适用场景
草稿文档、纯文字内容、极简哲学文档、为内容本身服务的场合。

### 反模式
- 任何强调色、装饰
- 色块、边框粗线
- 高信息密度

## 10. Vintage Typewriter（复古打字机）

**设计哲学**: 物理材质感。文档是物件。通过材质传递年代感。

### Visual DNA
- **色彩**: 牛皮纸色系。底 #e8e0d0、内嵌纸 #f0ebe0、正文 #3d3428 深棕。无鲜艳色。
- **字体**: Courier New 等宽为主 + Songti SC 混排。英文打字机感、CJK 宋体。
- **空间**: 紧凑 1.6 行距，打字机密度。压痕虚线定义空间。
- **形状**: 虚线、回形针、咖啡渍圆环、纸卡片 box-shadow。

### 签名元素
- **封面**: 牛皮纸卡片（嵌套 box-shadow）+ 压痕虚线 3 条 + 回形针 + 咖啡渍双层圆环 + DOC_001 等宽元信息
- **页脚**: "PAGE N OF 总" 等宽格式（counter(page) + counter(pages)）
- **标题**: H1 深棕 2px 底线 + 宋体（不是打字机字体，保持可读）
- **表格**: 打字机三线式 + dashed 单元分隔线
- **TOC**: `>>> P.<n>` 等宽页码前缀，不用 leader 点导引线

### 适用场景
档案感文档、机密文档、复古笔记、年代叙事、任何需要"打的纸"质感的内容。

### 反模式
- 彩色
- 无衬线字体（违背打字机 DNA）
- 现代界面感
