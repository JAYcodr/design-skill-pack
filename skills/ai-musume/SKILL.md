# ai-musume · AI 娘立绘

给「某家公司/某个模型」画一个拟人角色，并且让这一批角色**能并排站在一起不打架**。

系列感不靠画风，靠七条公式一致。少一条，图就散。

## 七条公式

1. **锁格式**：纯白背景、全身从头到脚、干净线稿、柔和赛璐璐上色、无场景无房间、地面只有很淡的接触阴影。
2. **定性格**：一张脸 + 一句气质。乐观/克制/慵懒/好奇——只选一个，别混。
3. **定轮廓**：给一个别人没有的形状（光环 + 彗星尾 / 战斧 / 角翼尾三件套 / 双发髻猫耳），同时**写明不要出现别家的特征**。这一句是防串图的关键。
4. **一个符号重复四到六次**：头饰、胸、腰、裙摆、鞋、武器，同一个图案反复出现，才叫签名。
5. **一个随身物**：书、云、海螺、录音笔、鲸鱼玩偶——把产品特点再抬一层。
6. **配色写死**：列出允许的颜色，并显式写 no orange / no green 这类反向禁色。颜色漂移是这批图最常见的失败。
7. **结尾统一**：`No text, no letters, no watermark, no subtitles, no company wordmarks.`

比例没那么重要，纵向、全身放得下就行。源头文档写 3:4；本机内置 `generate_image` 只支持 1:1 / 16:9 / 9:16 / 2:3 / 3:2，随便选个纵向的（2:3 最接近）；传 3:4 不报错，会被静默降成 1:1。

## 工作流

1. 读 `references/characters.md`，看目标家有没有现成提示词。有 → 直接抄整段，**一字不改**。
2. 没有 → 按七条公式新写一段，补齐「不要出现」清单。
3. 出图（白底、纵向）。不满意只改外形段，不要重写整段。
4. 定稿后**拿这张当垫图**出表情组 / 换姿势 / 场景变体：外形段整段保留，只替换最后一段 Pose。
5. 场景变体另存，不要拿回来垫图——场景、字幕会跟着长进新图里。

## 垫图禁忌

- **带字幕或平台水印的截图不要当垫图**，字会跟着长出来。
- 官方视觉是黑白橙这类强色的角色，垫图前先确认要的是哪条线（Grok 尤其）。
- 同一角色换姿势时，外形段一个字都别动；改了外形段就等于换人。

## 自检（出图后逐条过）

- [ ] 白底、全身、两只脚都在画里
- [ ] 那个「不要出现」的清单里，一件都没混进来
- [ ] 签名符号出现 ≥4 次
- [ ] 配色没有漂（尤其橙↔红、蓝↔紫、蓝↔绿）
- [ ] 画面里没有任何文字、字母、水印
- [ ] 放一排看，和同系列其它角色身高/头身比例接近

## 踩坑

- **prompt 里不要写真人画师名字**（「米山舞风格」这种）。上游会判 `content_policy_violation`（与第三方内容相似性）。只写描述。
- 不锁垫图，同一角色连出三版脸都不一样；半写实渲染尤其抽不准，做不成系列。
- 要三视图：横幅 3:2，三张立绘并排、等高等大、白底平光，模型不容易把尾巴/配饰放反。
- 接收端是飞书/微信时，Markdown 图片链接不会被解析——必须按文件发送。
