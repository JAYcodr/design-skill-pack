# 均值识别指南（用于诊断，不用于禁令）

> 用户钦定（CASE-006）：**单项技法不定罪，密度 + 无概念 + 均值化才定罪。**
> 用法：评审或自查时逐项过"何时土"；若命中"安全用法"的全部前提，则该项无罪。
>
> 这不是禁令清单。表里每条都是"训练数据里出现次数最多的答案"——它们出现次数多是因为常常够用。
> 你的概念若能把某一条用到先验不敢的程度（CASE-007 把"蓝色"淹没全屏），那就是大胆本身。
> 要防的只有一件事：**无意识地、舒适剂量地、因为"大家都这么做"而选中它。**

## 定罪公式

```
土 = 无概念 + 均值决策 + 特效堆砌（密度）
```

三要件缺一不可定罪：
- **无概念**：技法与产品概念无推导关系
- **均值决策**：该选项是同类项目的先验最高项（十个里九个这么选）
- **密度**：同类技法多处使用

判例对照：fadeInUp —— CASE-001 罪状（十处+全均值）/ CASE-006 无罪（全站唯一动效层+其余决策不均值）。glitch —— CASE-001 罪状（无概念装饰）/ CASE-004 无罪（CRT 材质固有行为+叙事转场）。

## 低分塌陷清单（先过这四条，再谈风格）

> 来源：ArenaGalleri 145 道题 × 3113 件作品的第三方普查（2026-11）。作品被淘汰，多数不是因为"不够好看"。

1. **跑不起来**：JS 报错 / 白屏 / 首屏空——最常见也最致命（实测低分作品就是 TDZ 报错白屏）。交付前过"零报错门"。
2. **内容缺段**：题面要求的板块没做（复刻题只做 1/4 段）。开工先列题面要求清单，逐条打勾。
3. **题面错位**：要求的 A 做成 B（复刻题做自创、用免责声明替代内容、转化题做纯概念）。先过 SKILL.md 第 0 步。
4. **同构空转**：每屏换色不换想法（24 节气只换颜色/花瓣）。判据：遮住品牌名，这一屏还剩什么只属于这道题？

第 1 与第 2 名往往完成度相同，差距是**想法密度 × 投入证据密度**——不是"再美一点"。

## 高危素材表

### 1. 霓虹青 + 品红 + 紫配色
- 何时土：cyber/AI 题材的默认配色，与概念无推导关系（CASE-001 判例）
- 安全用法：配色从概念推导（007 纯蓝 = 材质本身即概念；005 冷月 = register 服务叙事）

### 2. Orbitron / "未来感"第一默认字体
- 何时土：选它只因为"科技感"（001）
- 安全用法：字体系统从材质推导（006 JetBrains Mono = 终端骨架；007 Sigurd serif × Courier mono = 古典×终端对撞）

### 3. 渐变文字（background-clip:text）
- 何时土：标题/卡片/数字多处滥用（001 共 4 处）
- 安全用法：渐变即材质（如概念是"棱镜/极光"）且全场唯一处；否则用色彩纪律替代

### 4. glitch 故障动画
- 何时土：无概念装饰（001）
- 安全用法：材质固有行为 + 承担叙事转场（004 花屏 = CRT 信号噪声，且切换 3D→2D 场景）

### 5. 玻璃拟态卡片
- 何时土：与概念无关的"高级感"，密度使用（001）
- 安全用法：材质本身是玻璃/霜/冰且全场服从；否则删除

### 6. 粒子背景
- 何时土：与内容零关系的纯装饰（001 粒子宇宙）
- 安全用法：粒子即内容（概念本身是尘埃/星野/微生物）且有交互密度（002 级的"世界是活的"）

### 7. 自定义光标 dot+ring / 扫描线 / 暗角滤镜 / 装饰性 FPS 计数器
- 何时土：四件套通常一起出现——"高级感套餐"，全部无概念（001）
- 安全用法：光标/滤镜即材质（004 暗角是胶片暗室的材质一部分）；FPS 只在性能工具页出现

### 8. fadeInUp 滚动 reveal
- 何时土：每个区块一个 + 其余决策均值化（001）
- 安全用法：全站唯一动效层、统一参数、其余决策不均值（006：0.8s 统一 reveal，零动画库）

### 9. 深色渐变 hero + bento grid + 滚动劫持（SaaS 落地页套餐）
- 何时土：技术 SaaS 的均值套餐（006 反均值判例：全部避开）
- 安全用法：先过 Step 3 十问测试——这套组合十个项目九个用，写不出必然成立的理由就换

### 10. 黑底绿字终端（hackerman）
- 何时土：终端题材的第一默认（004 反例警示）
- 安全用法：004 示范——浅灰白底老式 GUI 质感；或 006——mono 字体承担骨架但页面是白底

### 11. vaporwave 霓虹粉紫复古
- 何时土：复古题材的第一默认（004 反例警示）
- 安全用法：004 示范——胶片暖调暗室；复古材质有几十种，vaporwave 只是均值最高的一种

### 12. 深蓝卡片 + 呼吸光晕图标启动屏（AI 产品均值）
- 何时土：AI/陪伴产品的默认启动屏（009 splash 判例：#0e0e18 + breathe 光晕）
- 安全用法：启动即叙事（004 暗房等待态；005 已装填等待态）；启动屏是仪式的第一幕，不是 loading 皮肤

### 13. 🧠💡✨ emoji 装饰
- 何时土：用 emoji 代替材质（009 TUI 判例：`🧠 thinking`）
- 安全用法：SOUL.md 判例反向读——"我的温暖来自内容，不是表情符号"；装饰需求用材质内物件回答（图钉/胶带/印章）

### 14. 主色 + 点缀强调色（"提亮眼"中间地带）
- 何时土：配色最安全也最平庸的形态——主色保守 + 强调色只敢小面积点缀（P5 警告）
- 安全用法：走极端——0 色 / 1 个语义色（且只落语义物）/ 2 色淹没 / 单色+温度配给

### 15. 老虎机式数字滚动
- 何时土：用随机闪烁假装物理（008 骰子判例，记录在案的小瑕疵）
- 安全用法：真实机制模拟（T03 机械因果链；005 棘轮）；2D 限制下可接受，但要知道这是妥协不是成立

### 16. 暖纸底 + 衬线标题 + 朱砂/铜金强调色（"中文高级感"三件套）
- 何时土：只因为"想显得高级/东方"就整组套上（普查：25 件浅色作品里 19 件暖米白）
- 安全用法：纸的材质有推导（013 海图纸＝岛/测绘的材质）；或干脆走另一个极端（002 零颜色）

### 17. 零售/烘焙海报套餐：圆印章 + 麦穗线稿 + 虚线圆插画 + 红色促销块 + "把秋天…"式大标题
- 何时土：无概念直接套（013 对照产出判例：执行干净、转化好，但换品牌名仍成立，用户判"太安全、太常见"）
- 安全用法：把促销信息翻译成世界观语言（013 本案例：开岛日 / 首航 / 物产价签 / 售完即退潮），而不是贴在版面上的促销块

## 工程陷阱（程序化贴图/自验判例）

> 来源：demo#2 八音盒自验三轮 + demo#1 相机编舞。进黑名单是因为会重复踩。
>
> 其中「跑不起来 / 路径裂图 / 字小到读不了 / 占位残留」可以交给 `scripts/quick_check.py` 当场量出来；控制台运行时错误、真实对比度、手感仍要看截图，脚本替代不了看图。

1. **canvas `save/restore` 还原 fillStyle** → `destination-out` 用半透明色打孔 = 假孔（实测 alpha 242/255）。打孔前确认 fillStyle 为全不透明
2. **贴图 offset 未初始化** → 等待态直接剧透全部内容。初始状态必须是"未上弦/未开始"的空白带
3. **木纹正弦振幅过大** → 渲染像大理石不像木头。低振幅细纹 + 偶发深 streak 才像
4. **没有相机编舞的立起** → 2D⇄3D 双重读法不成立（T01 禁忌的实证：003 第三轮自验才修掉"相机不成立"）
5. **"代码写了 = 效果对了"** → 禁止。截图自验循环（构建→截图→看图自评→修）到能交卷为止；不可截图项（声音/手感）诚实标注未验证
