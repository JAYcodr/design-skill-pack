# 外观账本：让"每次重新发明"有据可查

> 文字警告挡不住趋同——CASE-011 八组里七组底色停在浅米白；CASE-008 记录"纸 + 暖棕"已是第三次出现。模型每次新会话都从同一先验收敛，靠自觉记不住上次做过什么。账本把"最近长什么样"变成开工前看得见的事实。

## 记什么（只记事实，不记评价）

- 底色（body 背景色）
- 主色板（去掉黑白灰后的高频色，最多 3 个）
- 标题 / 正文字体
- 骨架特征：section 数、grid/flex 使用、圆角/细线倾向、是否有全屏图

## 怎么用

```bash
python3 scripts/ledger.py recent --n 8          # 开工前：最近 8 次交付的样子
python3 scripts/ledger.py check 新稿.html        # 和最近记录比：底色/字体/骨架撞没撞
python3 scripts/ledger.py add 成品.html --project 项目名 [--note "来源/概念一句话"]
```

- **开工前**读 `recent`，写一句"这次要避开哪几样"——底色、强调色、字体、布局、动效、素材各是一个决策点（CASE-011：逃出强调色不等于逃出底色）；
- **交付后** `add` 一笔；判决理由（过/不过 + 理由）仍回写 `calibration.md`，账本只记样子不记判决。

## 存储与隐私

- 默认 `$HOME/.frontend-design/ledger.jsonl`；`FRONTEND_DESIGN_HOME` 可改到项目内；
- 只在本机，不随 skill 分发；删掉目录即遗忘；
- 只存视觉指纹（颜色/字体/结构计数），不存页面内容。

## 边界

- **只记事实，不打分**：它不是评分器，不判断好坏；
- **重复不是罪**：同一品牌/同一系列项目本来该一致；账本只提醒"你在重复"，撞了要不要改由这次任务目标决定；
- **提示不是禁令**：不要为了躲账本而换一个更差的方案；
- **静态提取有误差**：渐变、图片背景、复杂 CSS 可能读不准，输出会标置信度；拿不准时以截图为准。
